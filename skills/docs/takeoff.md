# takeoff -- 无人机起飞

## 使用时机
当无人机在地面需要起飞时使用。这是大多数任务的第一步。

## 参数
- altitude: float, 目标离地高度（米，正数），默认 1.5
  - 室内允许范围为 0.5-4.0m
  - altitude=1.5 表示起飞到离地1.5米
  - ⚠️ 给正数！不要给负数！
  - 一般室内测试建议 1.0-2.0m

## 前提条件
- 电池 >= 30%
- 无人机未在空中
- 无人机已连接

## 执行流程
1. ARM 电机
2. 发送起飞指令
3. 上升到目标高度（target_z = current_z - altitude）
4. 到达目标高度后悬停

## 注意事项
- 起飞过程约 10-30 秒达到目标高度
- 起飞后默认进入悬停状态
- altitude 是正数目标离地高度，超出室内包线会被拒绝

## 输出
- actual_altitude: 实际达到的离地高度（米，正数）
- takeoff_time: 起飞耗时（秒）
