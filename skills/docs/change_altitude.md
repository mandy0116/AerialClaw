# change_altitude — 目标高度调整

## 使用时机
需要在当前位置升高或降低时使用。

## 参数
- altitude: float，目标离地高度（米）
  - altitude=2.0 → 调整到离地2米
  - 室内允许范围为 0.5-4.0m

## 前提条件
- 无人机在空中

## 执行流程
1. 获取当前高度，必须先执行get_position技能，否则调整高度
2. 校验目标高度是否在室内安全包线内
3. 纯垂直运动到目标高度，水平位置不变
4. 到达后悬停

## 注意事项
- 参数是绝对离地高度，不是相对变化量
- 巡航最低高度 0.5m，最高高度 4m
- 水平位置完全不变

## 输出
- previous_altitude: 变化前的高度（米）
- current_altitude: 变化后的高度（米）
- change: 变化量描述
